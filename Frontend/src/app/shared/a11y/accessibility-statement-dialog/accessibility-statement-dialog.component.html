הצהרת נגישות

אנו רואים חשיבות רבה במתן שירות שוויוני לכלל המשתמשים, ופועלים להנגשת האפליקציה לאנשים עם מוגבלות.

רמת הנגישות

האפליקציה הונגשה בהתאם לתקן הישראלי ת"י 5568, ברמת התאמה AA, ובהתבסס על הנחיות WCAG 2.2 ברמה AA.

אמצעי הנגישות באפליקציה

  • ניווט מלא באמצעות מקלדת
  • תמיכה בתוכנות הקראת מסך (NVDA, VoiceOver)
  • מבנה סמנטי ותגיות ARIA
  • ניגודיות צבעים תקנית, ומצבי ניגודיות גבוהה והפוכה
  • אפשרות להגדלת טקסט עד 200% ללא אובדן תוכן
  • התאמה לגלישה ממכשירים ניידים
  • תפריט נגישות ייעודי (הכפתור הצף בפינה השמאלית התחתונה)
